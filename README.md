# Antischool — Інтерактивна Карта Розмови та Онлайн-Суфлер

Інтерактивний веб-додаток для сервіс-менеджерів, кураторів та фахівців онбордингу Антишколи.

## 🚀 Можливості

- **8 послідовних кроків онбордингу студента:**
  1. Привітання та знайомство (зручно / не зручно)
  2. Анкета та графік занять (звірка даних або збір з нуля)
  3. Викладач та пропозиція носія (обов'язково для B1+, відпрацювання страхів з гарантією)
  4. Терміни підбору (2–7 робочих днів, бонусний Абонемент)
  5. Чат-бот як головний канал зв'язку (Telegram / Viber)
  6. Інформація про сервіс (правило скасування за 8 годин)
  7. Питання та довіра (контакт після 1-го уроку)
  8. Тепле завершення розмови

- **Живий суфлер (Live Teleprompter):**
  - Автоматична підстановка імені студента, імені менеджера та рівня у всі фрази.
  - Кнопка швидкого копіювання репліки в буфер обміну.
  - Підказки та інтонаційні акценти для менеджера.

- **CRM Чек-ліст та шаблони повідомлень:**
  - Інтерактивний чеклист обов'язкових дій після дзвінка (статус «ИО Подбор тичера», помітки по носію).
  - Шаблон вітального SMS у 1 клік.
  - Модальне вікно сценаріїв «Не дозвонився?».

- **Таймер дзвінка та навігація:**
  - Вбудований секундомер контролю тривалості розмови.
  - Гарячі клавіші `1`–`8` для швидкого перемикання етапів.

## 📦 Розгортання (Deployment)

### Vercel
Проект повністю налаштований для миттєвого деплою на Vercel через файл `vercel.json`.
1. Підключіть репозиторій на [Vercel](https://vercel.com/new).
2. Натисніть **Deploy**.

### Локальний запуск
Відкрийте `index.html` у будь-якому браузері або запустіть:
```bash
npx serve .
```
